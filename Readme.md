# SELF HOSTING INVENTORY

A Python-based desktop application for SELF HOSTING INVENTORY using MIFARE Classic 4K, EV1 and EV3 smart cards.


## Installation

1. Install system dependencies (for PCSC):
   - **Linux**: `sudo apt install pcscd libpcsclite1 git python3-pyqt5`
   
2. Install Python dependencies:
   ```bash
   pip3 install -r requirements.txt
   ```
